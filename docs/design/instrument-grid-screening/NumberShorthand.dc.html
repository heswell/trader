Typing: the parsed value shows as you type
mkt cap $>30bn
= 30,000,000,000
Not a number: refused inline, nothing applied
mkt cap $>30bx
Use a number with k, m, bn or tn
Committed: shorthand on screen, the raw value in the query
mkt cap $>30bn
marketCapUsd > 30000000000

The filter keeps the raw number. Pills, the hover summary and the field all show it in the shortest exact shorthand, so 30000000000 reads as 30bn and 1250000 as 1.25m. Saved screens hold raw values, so they don't depend on how the number was typed.
