# trader

Reusable trading front-end (instrument grids, market depth / price ladder, order ticket, order & trade blotters) built on [Vuu](https://github.com/finos/vuu) UI components and the `vuu-portal`, exercised by a realistic simulated backend (exchange simulator built on [hft-limit-order-book](https://github.com/heswell/hft-limit-order-book) plus an OMS) running on [vuu-websocket](https://github.com/heswell/vuu-websocket).

Status: Phase 0 (foundations) in progress.
